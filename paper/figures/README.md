# Figures

One folder per figure, each with a README that says what the figure shows, which files it contains, and how they
were made. The figure scripts are in `scripts/paper/figures/` (uv project `scripts/paper`). Which code the runs
used is in `../README.md`; every score is on each dataset's first training sequence (01) of the Cell Tracking Challenge.

| Folder | Figure |
|---|---|
| `fig1/` | Fig. 1: Automahout carries out the operations of tracking |
| `fig2/` | Fig. 2: autonomous tracking on three datasets |
| `table1/` | Table 1: autonomous tracking on three datasets (scores, detectors, operations) |
| `supp/tableS1/` | Supplementary Table 1: other conditions and a Trackastra baseline |
| `supp/figS1/` | Supplementary Fig. 1: taking a closer look (the VLM check) |
| `supp/figS2/` | Supplementary Fig. 2: merges, misses and duplicates per frame on the embryo |
| `supp/figS3/` | Supplementary Fig. 3: an excerpt of a run log |
