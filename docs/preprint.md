# The preprint

["Automahout: an autonomous image analysis system for cell tracking"](https://doi.org/10.64898/2026.11.04.764293)
(bioRxiv) describes the code at tag [`preprint-v1`](https://github.com/automahout/mastodon-automahout/tree/preprint-v1) and benchmarks it on three Cell
Tracking Challenge datasets: Fluo-N2DL-HeLa, PhC-C2DL-PSC and Fluo-N3DH-CE.

| What | Where |
|---|---|
| The figures and tables, with the data and the script behind each | [`paper/`](https://github.com/automahout/mastodon-automahout/tree/main/paper) ([README](https://github.com/automahout/mastodon-automahout/blob/main/paper/README.md)) |
| Rebuilding the benchmark from public data, in one command | [`scripts/reproduce/`](https://github.com/automahout/mastodon-automahout/tree/main/scripts/reproduce) ([README](https://github.com/automahout/mastodon-automahout/blob/main/scripts/reproduce/README.md)) |
| The runs' outputs, Mastodon projects and the embryo's trained model | SSBD:repository `ssbd-repos-000552`, <https://doi.org/10.24631/ssbd.repos.2026.11.552> |

The input images and ground truth are the Cell Tracking Challenge's and are not redistributed; download them from
<https://celltrackingchallenge.net/2d-datasets/> and <https://celltrackingchallenge.net/3d-datasets/>.

To cite the preprint, see [Citation](citation.md).
